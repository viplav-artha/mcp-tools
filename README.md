# mcp-tools

An MCP (Model Context Protocol) server built with the official MCP Python SDK's `FastMCP` high-level
API, exposing tools over Streamable HTTP. Converts the hand-rolled tools from the companion learning
repo [tools](https://github.com/viplav-artha/tools) (a custom tool registry + agent loop built against
AWS Bedrock's Converse API) into real MCP tools, to understand how MCP standardizes tool-calling across
clients.

## Status

Early stage — being built one file at a time, each with a written walkthrough of why it exists and how
it works. No runnable code yet.
